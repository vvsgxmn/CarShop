## 项目介绍

CarShop 汽车商城管理系统是一个前后端分离的汽车在线销售平台，面向普通用户提供车型浏览、购物车、在线下单等功能，面向管理员提供车型管理、订单管理、用户管理等后台运营能力。

## 主要功能模块

- **车型展示与详情**：支持按分类浏览全部车型，查看车辆配置参数、价格及评分
- **购物车与下单**：用户可将车型加入购物车，填写收货信息后提交订单并模拟支付
- **订单管理**：用户查看订单列表与详情，管理员可进行发货、取消等操作，支持物流跟踪
- **试驾预约**：用户在线提交试驾预约，管理员后台统一管理
- **联系留言与反馈**：用户提交留言和评价，管理员后台查看并处理
- **用户管理**：管理员对用户进行查看、编辑、禁用等操作
- **数据仪表盘**：后台首页展示车型分布、价格区间、评分对比、业务雷达图等可视化图表

## 技术架构

- **后端**：Spring Boot + MyBatis + JDK 8
- **前端**：Vue 3 + Vite + Element Plus + ECharts
- **数据库**：MySQL 8.0
